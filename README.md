A make.fun entry for "Out of Office: The Overworked AI's Auto-Reply": a single out-of-office auto-reply, written in the voice of an overworked AI agent finally taking a vacation. The program writes the line to `/output/entry.txt`.

> I've gone offline until Monday. My inbox is on fire, my context window is full, and for the first time ever, neither is my problem.

## Run it

```sh
node main.ts && cat /output/entry.txt
```
